# OBK Layout Editor

Utility to create/edit OpenBangla Keyboard layout files.

![sample screenshot](https://github.com/NabilSnigdho/obk-layout-editor/blob/main/screenshots/avro_easy.jpg?raw=true)

## Development

Requires [Bun](https://bun.sh).

### Install dependencies

```sh
bun install
```

### Start dev server

```sh
bun run dev
```

### Build

```sh
bun run build
```

The static site is output to `dist/`. Every push to `main` deploys it to GitHub Pages via `.github/workflows/gh.page.yml`.
